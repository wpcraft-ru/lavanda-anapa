# RFC: Карточка номера

## Meta
- **URL:** `/rooms/econom/`, `/rooms/standard/`, `/rooms/family/`
- **Тип:** product-card
- **Цель:** Детальная информация → конверсия в звонок
- **Аудитория:** Зависит от номера (эконом → соло, стандарт → пары, семейный → семьи)
- **Статус:** draft

## Sections

### 1. Заголовок + цена
- **H1:** Тип номера
- **Цена:** крупно «от X ₽/ночь»
- **Подзаголовок:** для кого подходит

### 2. Галерея (заглушка)
- **Placeholder:** цветной блок с иконкой

### 3. Описание
- **2-3 абзаца:** атмосфера, для кого, что внутри

### 4. Удобства в номере
- **Сетка иконок:** список удобств конкретного номера

### 5. CTA
- **Кнопка «Позвонить»** + телефон
